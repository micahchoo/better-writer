# Fork of Elicit; the wiki is dropped here

Better-writer is a fork of Elicit, not an evolution of it. The self-knowledge wiki — vault, clerk, docket, sounding, harvesting, pieces, marginalia — is not carried into this tree; upstream Elicit keeps it. The fork keeps only the local-model spine (`llm.ts`) and the "model composes, code verifies" discipline. The repo root becomes the new project; the dead machinery lives only in git history.
